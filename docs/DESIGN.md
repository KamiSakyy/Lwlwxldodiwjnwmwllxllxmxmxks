# MailGram 3.1 — оформление, переделанное с нуля

Дизайн собран заново (не косметика поверх старого): 15 экранов, вся палитра, все иконки и
фоны. Ориентир — Telegram 12 для iOS и тёмная тема iOS 26: чистый чёрный фон, стекло
только в навигационном слое, крупная типографика, скруглённые пузыри с «хвостиком».

## Палитра

| Роль | Чёрная тема (по умолчанию) | Светлая тема |
|---|---|---|
| Фон | `#000000` | `#F2F2F7` |
| Поверхность (карточки, пузырь входящего) | `#1C1C1E` | `#FFFFFF` |
| Вторая поверхность (пилюли, чипы) | `#2C2C2E` | `#E9E9EE` |
| Акцент | `#3B9EFF` | `#0A84FF` |
| Пузырь исходящего | градиент `#3B9EFF → #0A6BFF` | `#0A84FF` |
| Основной текст | `#FFFFFF` | `#000000` |

Одинаковые имена цветов в `values/` и `values-night/`, поэтому одна и та же разметка
одинаково читается в обеих темах. Тёмная тема теперь **по умолчанию** (раньше зависела от
настройки системы — из-за этого приложение открывалось светлым).

## Слои

* **Навигационный слой** — стеклянный: шапка списка, шапка чата, поле ввода, панель выбора,
  нижние панели просмотрщика (`@drawable/bg_nav_bar`, `@drawable/bg_bottom_bar` с волосяной
  линией). Только здесь используется полупрозрачность.
* **Контент** — непрозрачный: карточки настроек `@drawable/bg_card`, пузыри сообщений,
  меню вложений, обои чата (радиальные градиенты в `bg_chat_wallpaper`).

## Типографика и размеры

* Заголовок списка чатов — 32sp bold, подпись аккаунта и число непрочитанных — 12sp.
* Шапка чата — имя 17sp bold, состояние 13sp акцентом.
* Пузырь — текст 16sp, время и статус 11sp, скругление 18dp с «хвостиком» 6dp.
* Строка списка — аватар 54dp, имя 17sp, превью 15sp, время 12sp, бейдж 20dp.
* Строки настроек — 54dp высотой, шеврон 20dp, разделители с отступом 16dp.

## Что именно исправлено в причинах вылетов и «невидимых» элементов

1. **`?attr/...` в ресурсах** (49 drawable и 13 разметок) — из-за него элементы могли не
   нарисоваться или ломалась инфляция. Сейчас в ресурсах нет ни одного `?attr/`
   (проверяется скриптом `tools/check_refs.py`).
2. **ClassCastException при открытии чата**: строка «закреплённое сообщение» — это
   `LinearLayout`, а в коде поле было объявлено как `ImageView`; дженерик-приведение падало
   сразу при входе в переписку. Исправлено, добавлен `tools/check_types.py`, который ловит
   такой класс ошибок до сборки.
3. **Настоящий edge-to-edge**: нижние системные инсеты отдаются списку/корню экрана
   (`Ui.applySystemBars(activity, верх, низ)`), поэтому контент не перекрыт панелью жестов
   и клавиатурой; шапки получают верхний инсет и рисуются под строкой состояния.
4. **Светлая тема**: цвет цифр PIN-клавиатуры был жёстко белым — теперь из палитры; статусы
   на экране входа тоже берут цвета из темы, а не из литералов.

## Инструменты (офлайн-проверки перед сборкой)

| Скрипт | Что проверяет |
|---|---|
| `tools/check_ids.py` | каждый `R.id.*` из кода есть в разметке/меню этого экрана |
| `tools/check_types.py` | тип `findViewById` совпадает с виджетом в разметке (ловит CCE) |
| `tools/check_refs.py` | все ссылки `@drawable/@color/@string/@style/...`, родители стилей, `app:` в values |
| `tools/make_themes.py` | собирает `values/` и `values-night/themes.xml` с одинаковым набором стилей |
| `tools/make_drawables*.py` | генерирует фоны и иконки без `?attr/` |
| `tools/simulate_ratchet.py` | сценарии Double Ratchet (рукопожатие, смены DH, подделки, replay) |
