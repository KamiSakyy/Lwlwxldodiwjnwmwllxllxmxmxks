# Web APK Studio

Небольшое Android-приложение на Java для **полностью офлайн-упаковки сайта в настоящий устанавливаемый APK**.

## Возможности

- выбрать один `index.html` или ZIP-проект с `index.html`, CSS, JavaScript, изображениями и другими локальными файлами;
- задать имя приложения и Android package ID, например `com.company.mysite`;
- выбрать собственную картинку-иконку и включить автоповорот экрана;
- подписать сайт-APK постоянным RSA-ключом, зашифровать резервную копию ключа и восстановить её после переустановки;
- сохранить APK через системный выбор файлов;
- собирать сам Web APK Studio в **GitHub Actions**: его APK сохраняется в пределах 1 000 000 байт, а workflow проверяет подписи и прогоняет многомегабайтный smoke-тест генератора.

## Офлайн-сборка сайта на телефоне

После установки Web APK Studio интернет не нужен. Приложение распаковывает локальные исходники в APK-шаблон с Android `WebView`, меняет package ID и название, пересоздаёт иконки, подписывает APK и предлагает сохранить его. Android SDK/Gradle на телефоне не устанавливаются и не скачиваются.

Для ZIP положите `index.html` в корень либо в одну верхнюю папку архива. Если внутри несколько стартовых HTML-файлов, поместите один `index.html` в корень сайта. Одиночный HTML импортируется как `index.html`; отдельные CSS/JS/изображения для него можно добавить через ZIP.

Сайт открывается из локальных APK assets. JavaScript включён; Android WebView использует установленный на устройстве системный движок. У приложения сайта нет разрешения на интернет: удалённые CDN, API, шрифты и URL не будут работать офлайн — сохраните необходимые файлы внутри ZIP.

## Размер проекта и APK

Для исходников сайта и создаваемого сайт-APK нет искусственного лимита 1 МБ или 50 МБ. ZIP и одиночный HTML копируются потоком, поэтому большие проекты не загружаются целиком в память. Практические пределы — свободное место на устройстве, число файлов (до 10 000), ZIP32 (ZIP64 пока не поддерживается; предел формата — около 4 ГБ) и ограничения файловой системы. Отдельно, APK самого Web APK Studio по-прежнему удерживается в пределах 1 000 000 байт.

## Постоянная подпись и обновления

Каждый созданный сайт-APK подписывается тем же RSA-ключом, который хранится в закрытых данных Web APK Studio. Пока сам генератор обновляется установкой поверх прежней версии (без очистки данных), новые APK с тем же package ID устанавливаются как обновления. В разделе «Подпись» можно создать зашифрованную паролем резервную копию ключа и затем импортировать её после переустановки генератора или на другом устройстве. Номер версии создаваемого APK увеличивается автоматически для каждого package ID. Храните файл и пароль отдельно: без прежнего ключа Android не примет APK поверх установленного приложения.

Сайт-APK получает JAR/v1 и APK Signature Scheme v2. SHA-256/RSA-подписи проверяются через Android `apksigner` в GitHub Actions. В созданных APK также можно включить автоповорот; по умолчанию сохранена портретная ориентация.

У самого Web APK Studio также должен быть постоянный release-ключ, иначе обновление конвертера сотрёт его данные и ключ созданных приложений. Поэтому CI берёт keystore из защищённых GitHub Actions secrets, а не из публичного репозитория. До настройки секретов Actions запускает сборочные и signing-smoke tests, но намеренно не публикует новый конвертер APK.

## Сборка APK через GitHub Actions

В `.github/workflows/android.yml` настроена сборка **только для ветки Arena этой сессии** и ручной запуск `workflow_dispatch`. Постоянный ключ Web APK Studio читается из secrets `WEBAPK_SIGNING_KEYSTORE_B64`, `WEBAPK_SIGNING_STORE_PASSWORD`, `WEBAPK_SIGNING_KEY_ALIAS` и `WEBAPK_SIGNING_KEY_PASSWORD`. Keystore — PKCS#12; закрытый ключ нельзя помещать в публичный репозиторий. Пока секреты не настроены, workflow выполняет тесты, но пропускает публикацию APK.

После добавления секретов workflow собирает конвертер и Android-шаблон, проверяет размер конвертера (до 1 000 000 байт), проверяет v1/v2-подписи и проводит smoke-test 3-МБ APK, автоповорота и экспорта/импорта signing key. APK и исходный ZIP сохраняются как артефакты Actions и в `dist/` ветки.

Исходный проект также можно собрать из Android Studio с Android SDK 35 и Gradle 8.9.
