## Что изменено (по пунктам задания)

### 1. Скачивание файлов
Добавлен класс `com.github.android.webview.GHRDownloadListener` (`android.webkit.DownloadListener`):
* http/https → `DownloadManager` (системная папка «Загрузки», уведомление, докачка, скачивание продолжается даже если закрыть вебвью);
* остальные схемы (`data:`, `blob:`) → `Intent.ACTION_VIEW`;
* имя файла — `URLUtil.guessFileName`, MIME — из события WebView.

Внедрён вызовом `setDownloadListener` в оба реальных вебвью-хоста (`webview/viewholders/f`,
`webview/viewholders/LegacyGitHubWebView`). В официальном приложении обработчика загрузок не было
вообще (`setDownloadListener` — 0 вхождений), поэтому такие ссылки просто не скачивались.

### 2. Редактор файлов
* шкала шрифта кода `code_text_size_xxs…xxl`: 11–17 → 13–19 sp (+2 sp);
* полю редактора добавлен межстрочный интервал 1,15;
* моноширинный `roboto_mono`, подсветка и подсказки оригинала сохранены.

### 3. Дизайн
* Внешний вид **официальный**: иконка и название приложения не изменялись.
* Внутри приведён к актуальной палитре GitHub: фон светлой темы `#eff0f5` → `#f6f8fa` (canvas-subtle);
  ночная тема не тронута. Плюс читабельность редактора из п. 2.

### 4. Оптимизация
* Firebase Analytics / Crashlytics / Performance выключены (`meta-data` манифеста);
* отключён сбор рекламного идентификатора (`google_analytics_adid_collection_enabled=false`, `ssaid`);
* удалены разрешения `com.google.android.gms.permission.AD_ID` и `android.permission.ACCESS_ADSERVICES_*`;
* dex и ресурсы сжаты (deflate) — быстрее установка и меньше чтения с диска.

## Как собрано (воспроизводимо)

1. База — официальный `com.github.android` 1.279.0 (vc 950) из XAPK с APKPure:
   `base` 41 988 186 + `config.mdpi` 54 617 + `config.arm64_v8a` 53 576.
2. `apktool 2.9.3 d` базы и сплитов (сплиты декодируются отдельно — внутри уже скомпилированные
   9-patch и бинарный XML, которые aapt2 повторно не примет).
3. `python3 tools/mod_github_ru.py <декод> --ru-dir tools/i18n/ru --splits <декоды сплитов>` —
   манифест (снятие атрибутов сплитов и API35-алиаса, выключение аналитики), слушатель загрузок,
   редактор, дизайн, языки, слияние mdpi/arm64 из сплитов. Пакет при этом **не переименовывается**
   (флаг `--rename-package` — опция, по умолчанию выключена).
4. `apktool b` → `python3 tools/repack_apk.py … --meta-from <база>` (сжатие dex, выравнивание
   `resources.arsc` на 4 и `lib/*.so` на 16 КБ, возврат лицензий) → `apksigner sign` (v3).
5. Контроль — `python3 tools/check_apk.py <apk> <база>`: 21 проверка (официальный пакет, OAuth-хост,
   класс загрузки, русские строки, официальная иконка, выравнивание, вес). Дополнительно:
   `aapt2 dump badging` (пакет/версия как у оригинала), `aapt2 dump resources`
   (**0 потерянных имён ресурсов**), обратный декод apktool (все 5 dex валидны).

## Технические ограничения (для будущих модов)

* В 1.279.0 первый dex (`classes.dex`) содержит **ровно 65 536 ссылок на методы** — предел формата.
  Любая новая ссылка в нём ломает сборку (`Unsigned short value out of range`). Новый класс положен
  в 5-й dex, вызовы — в 3-й; для `setLineSpacing` в 1-м dex освобождён один слот (единственный вызов
  `Log.w` убран, `move-result` заменён на `const/16 0x0` — тип регистра сохранён).
* `<uri-relative-filter-group android:allow=…>` (API 35+) и `android:queryAdvancedPattern` не
  понимает aapt2 из apktool 2.9.3 — API35-алиас удалён целиком, разбор ссылок остаётся на
  классическом `DeepLinkAliasActivity` с теми же исключениями путей.
* Атрибуты `android:requiredSplitTypes` / `android:splitTypes` сняты — иначе одиночный APK
  (без split-ов) не установится.

## Установка

1. Удалите официальное приложение GitHub (подпись другая, поверх не встанет).
2. Установите `handoff/GitHub-1.279.0-mod.apk`.
3. Войдите в GitHub как обычно.
