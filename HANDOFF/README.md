# HANDOFF

Здесь сохраняются APK и source ZIP по версиям; release workflow не удаляет предыдущие файлы. Ранее выданный ARM64 debug APK сохранён. Новые сборки — minified **release APK** с монотонно растущим `versionCode` и постоянным ключом.

Исходные ZIP создаются release workflow с номером версии в имени; они содержат исходники, workflow и файлы подписи и должны оставаться меньше 1 MB. Новые релизы добавляются без удаления предыдущих.

Файлы подписи `nox-release-key.p12` и `nox-release-key-password.txt` также лежат здесь. Любой человек с доступом к ним сможет подписывать APK как обновления приложения; держите репозиторий/архив приватными и сделайте офлайн-резервную копию. SHA-256 сертификата — в `nox-release-fingerprint.txt`.

Первый release APK устанавливается отдельно от прежнего debug APK из-за отличающихся package ID и сертификата. Следующие release версии можно устанавливать поверх предыдущих.
