# Постоянная подпись Android-релизов

APK подписывается постоянным PKCS#12 ключом, alias `nox-release`. Workflow читает `nox-release-key.p12` и пароль из `nox-release-key-password.txt` прямо из `HANDOFF`; GitHub Actions secrets не требуются. Публичный сертификат и fingerprint доступны отдельно.

## Критическое предупреждение

По запросу владельца приватный keystore **и пароль** включены в `HANDOFF` и в source ZIP. Это намеренно небезопасно: любой, кто скачает репозиторий или архив, сможет создавать APK, подписанные как обновления этого приложения. Храните репозиторий/архив приватно и сделайте офлайн-резервную копию. APK содержит подпись и публичный сертификат, но не приватный ключ.

## Версии и обновления

Workflow строит minified `release` APK при push в ветку сессии или вручную через Actions. `versionCode` равен номеру запуска workflow, `versionName` имеет вид `1.0.N`. Для каждого номера создаются отдельные APK и source ZIP; старые файлы не удаляются. Не меняйте и не заменяйте keystore, иначе Android откажется устанавливать обновление поверх предыдущего.

## Установка

Ранее выданный debug APK использует package ID с суффиксом `.debug` и другой сертификат. Первый release APK нужно установить отдельно. Последующие release APK, подписанные тем же ключом, устанавливаются как обычные обновления.
